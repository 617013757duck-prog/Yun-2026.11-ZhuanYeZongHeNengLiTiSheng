# C3 · 异常交易告警展示设计

本设计已在 `streamlit_app.py` 中实现，演示时按以下层次讲解。

## 1. 风险分级（与模型联动）

| 等级 | 判定条件 | 展示 | 处置建议 |
| --- | --- | --- | --- |
| 高风险（告警） | 欺诈分数 ≥ **0.17** | 整行浅红底 + 红色徽标 + 列表「告警」标记 | 立即拦截 / 人工复核 |
| 关注（预警） | 0.08 ≤ 分数 < 0.17 | 橙色徽标 + 浅黄底 | 加入观察名单 |
| 正常 | 分数 < 0.08 | 绿色徽标 | 正常放行 |

- 三条线全部来自线A 的模型产物 `models/metrics_fraud_final.json` 的 `thresholds` 字段，页面自动读取，改动模型产物即同步更新，不需要改前端代码。
- 告警线 0.17 = 验证集 F1 最优；关注线 0.08 = 在 F1 不低于告警线 95% 且误报率 ≤2.5 倍的前提下取召回最高；严格线 0.11 = 误报率 ≤0.5% 的最小阈值，可作为误报预算紧张时的备选。
- 早期版本曾把阈值硬编码为 0.79 / 0.50，与模型分数尺度强耦合，换模型即失效，故已废弃。

> 注：0.79 / 0.50 是 v1 模型（`scale_pos_weight=27.58`）的阈值，只在期中 PPT 与历史讲稿中出现过；正式模型 v2 已改为 spw=1，阈值体系随之重算。

## 2. 展示形式（列表 / 标红 / 徽标 / 统计）

1. **KPI 概览**：交易总数、高风险告警数、关注数、告警率、平均欺诈分数。
2. **逐笔列表**：行号、产品类别、置信度、欺诈分数、风险等级、告警、处置建议；
   高风险行整行标红，正常行不加底色。
3. **单笔明细**：产品五类概率条形图 + 欺诈分数进度条（>阈值时提示“高于阈值”）。
4. **结果导出**：一键下载完整预测结果 CSV（UTF-8-BOM，Excel 可直接打开）。

## 3. 交互与防错

- 上传前先校验：缺列 / 重复列 / 非数值内容 → 页面顶部给出明确错误，不进入预测。
- 额外列自动忽略并提示（如误传带标签的训练切片）。
- 支持 UTF-8 与 GBK 编码；中文列名/路径均已验证。
- 「使用演示样例」一键加载 10 行数据（覆盖 5 类产品 × 2 种欺诈标签），用于课堂演示与截图。

## 4. 演示动线（建议 30 秒）

1. 打开页面 → 点开「使用演示样例」→ KPI 显示 10 笔中若干笔告警；
2. 指出标红行与“告警”徽标 → 展开单笔明细，说明分数与阈值关系；
3. 上传缺列文件 → 展示校验报错（体现系统可用性）；
4. 下载预测结果 CSV → 与真实标签对照表核对（样例核对，不代表整体性能）。

# IEEE-CIS 数据卡片

## PPT 第 3 页可直接粘贴

| 模板栏目 | 文案 |
| --- | --- |
| 数据来源 | 公开竞赛 IEEE-CIS Fraud Detection（Kaggle），使用本地两张训练数据表 |
| 数据规模 | 交易表 590,540 行 × 394 列，身份表 144,233 行 × 41 列。按交易 ID 左连接后为 590,540 行 × 434 列（含主键和标签） |
| 数据类型 | 结构化表格，含交易金额、相对时间、匿名卡片与地址代码、邮箱域、设备信息和匿名工程特征 |
| 标签类型 | `isFraud` 欺诈二分类（0/1），`ProductCD` 产品代码五分类（C/H/R/S/W） |
| 类别分布 | 欺诈 20,663 笔（3.50%）。产品 W 类 439,670 笔（74.45%），其余四类见图 |
| 数据清洗措施 | 左连接保留全部交易，删除合并后缺失率 >99% 的 9 列，数值用中位数填充，类别用 Unknown 填充并编码，按欺诈标签 80/20 分层划分 |
| 数据增强措施 | 保留真实样本。欺诈任务使用类别权重并在验证集调阈值，产品分类使用类别权重 |
| 其他数据问题及措施 | 身份关联覆盖 24.42%，通过左连接与缺失填充保留交易。欺诈占 3.50%，用分层、加权及 F1/误报率评估。匿名字段按分组编号说明，避免对单列作业务归因 |
